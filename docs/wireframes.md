# Каркаси екранів

Редагований файл diagrams/wireframes.drawio; знімок ../output/report-assets/wireframes.png.

Вхід/реєстрація без навбару. Аналіз: заголовок, підказка, центральний вибір фото й кнопка. Результат замінює форму: фото 1/3 ширини, аналітика 2/3. Довідник: auto-fit картки. Стаття: фото, опис, акордеон. На вузьких екранах — вертикальне компонування. Історія на схемі не показана, бо функціонал вилучено.

Мобільне компонування оновлено 15.11.2026: до 600 px бічної панелі немає, використовується бургер зі спливним меню. Актуальний редагований каркас: diagrams/wireframe-mobile.drawio. Джерело розташування меню узгоджене з фактичним Navbar.tsx.
