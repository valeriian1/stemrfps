# Каркаси екранів (Wireframes)

## Вхід (Десктоп/Мобільний)
```text
+-----------------------------------+
|                                   |
|          Вхід в систему           |
|                                   |
|   Email: [____________________]   |
|                                   |
|   Пароль: [___________________]   |
|                                   |
|         [   УВІЙТИ   ]            |
|                                   |
|    Немає акаунта? Реєстрація      |
|                                   |
+-----------------------------------+
```

## Дашборд (Десктоп)
```text
+-------------------------------------------------------------+
| AgroDiag    Дашборд    Поля    Діагностика    Журнал [Вийти]|
+-------------------------------------------------------------+
|                                                             |
| Дашборд                                                     |
|                                                             |
| +----------------+ +-----------------+ +------------------+ |
| | Полів: 3       | | Обстежень: 12   | | Хвороб (30д): 4  | |
| +----------------+ +-----------------+ +------------------+ |
|                                                             |
| +-----------------------------+ +-------------------------+ |
| | Топ-3 хвороби               | | Останні обстеження      | |
| | 1. Бура іржа ====== 60%     | | Поле 1 - Іржа (98%)     | |
| | 2. Сажка === 30%            | | Поле 2 - Здорове (99%)  | |
| | 3. Септоріоз = 10%          | | Поле 1 - Сажка (85%)    | |
| +-----------------------------+ +-------------------------+ |
+-------------------------------------------------------------+
```

## Дашборд (Мобільний)
```text
+-------------------------+
| AgroDiag            [=] |
+-------------------------+
| Дашборд                 |
|                         |
| +---------------------+ |
| | Полів: 3            | |
| +---------------------+ |
| +---------------------+ |
| | Обстежень: 12       | |
| +---------------------+ |
| +---------------------+ |
| | Хвороб (30д): 4     | |
| +---------------------+ |
|                         |
| Топ-3 хвороби           |
| 1. Бура іржа ===== 60%  |
|                         |
| Останні обстеження      |
| Поле 1 - Іржа (98%)     |
+-------------------------+
```
