# Каркаси екранів

Каркас дашборда для комп’ютера збережено в diagrams/wireframe-desktop.drawio, для телефону в diagrams/wireframe-mobile.drawio. Загальна схема екранів міститься в diagrams/wireframes.drawio.

Форми входу й реєстрації не мають навігаційної панелі. На сторінці аналізу розміщено заголовок, підказку, область вибору фото та кнопку запуску. Результат замінює форму: фото займає приблизно третину ширини, опис і показники займають решту.

Картки довідника підлаштовуються під доступну ширину. Стаття містить фото, опис і акордеон. На вузьких екранах блоки розташовані вертикально.

До 600 px бічну панель замінює верхній рядок із бургером. Спливне меню містить аналіз, довідник, історію та акаунт. Іконка історії не виконує дій.
