# Потік користувача

Актуально 10.11.2026. Редагована діаграма: diagrams/user-flow.drawio. Знімок: ../output/report-assets/user-flow.png.

Вхід або реєстрація → валідація → /analyze → вибір і перевірка фото → запуск → очікування → дашборд → стаття хвороби.

Альтернатива: /analyze → /diseases → /diseases/:id. Три переходи від форми входу: «Увійти», «Довідник», «Детальніше». Це уточнення викладача зі слів користувача, а не окремий пункт PDF.

Помилки полів залишають у формі. Непридатне фото можна замінити. Скасування повертає готове фото. Новий аналіз очищує попередній результат. Акаунт → Вийти повертає /login. Реальної сесії, історії та збереження немає.
