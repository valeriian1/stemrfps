# Потік користувача

Діаграми: diagrams/flow-analysis.drawio і diagrams/flow-catalog.drawio.

1. Заповнити форму входу або реєстрації.
2. Виправити поля, якщо з’явилось повідомлення про помилку.
3. На сторінці аналізу вибрати фото та дочекатися перевірки.
4. Запустити аналіз і переглянути дашборд.
5. Відкрити статтю про хворобу або почати новий аналіз.

Довідник також доступний без завантаження фото. Після входу користувач відкриває каталог і переходить із картки до статті. Разом це три переходи між екранами, відповідно до уточнення викладача.

Непридатне фото можна замінити. Скасування аналізу повертає підготовлене фото. Новий аналіз очищує попередній результат. Дія «Вийти» в меню акаунта відкриває /login. Реальної сесії та збереження результатів немає.
