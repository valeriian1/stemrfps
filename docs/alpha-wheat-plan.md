# Обсяг STEM-проєкту

Фронтенд для роботи з фотографіями листя пшениці: форми входу й реєстрації, вибір фото, демонстраційний аналіз, дашборд, довідник і статті про хвороби.

Серверної авторизації, історії аналізів і експорту немає. Сервіс повертає фіксований приклад результату. Дані зберігаються лише в пам’яті вкладки.

Використано React, TypeScript, Vite, React Router, Zod, CSS і локальний шрифт Geist. Реалізовано перевірку файлів, скасування операцій, повідомлення про помилки та клавіатурну навігацію.

Вимоги описано в SP_Front.pdf. Перевірка відповідності міститься в requirements-audit.md, результати тестування у verification.md. Діаграми збережено в diagrams.
