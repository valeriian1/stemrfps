# Coursework — фронтенд аналізу фото пшениці

Актуальний стан: 10.11.2026. React + TypeScript + Vite. Основні екрани: вхід/реєстрація, аналіз із дашбордом результату, каталог і стаття хвороби.

## Запуск

Потрібні Node.js 22.14+ та npm.

```sh
npm ci
npm run dev
```

Відкрийте адресу Vite. Логін: довільні 3–64 символи; пароль: 8–128 символів. Реєстрація перевіряє повтор пароля. Це лише форми: обліковий запис і сесія не створюються, маршрути доступні напряму.

## Сценарій

Натисніть пунктирний блок, оберіть JPEG/PNG/WebP до 10 МіБ та запустіть аналіз. Через приблизно 2 с форму замінює дашборд. Під час очікування доступне скасування. Результат містить фото, опис, кільцеву діаграму та сегментовану шкалу; посилання веде до статті. «Аналізувати інше фото» очищує стан.

Мок не розпізнає фото: приклад завжди показує буру іржу, площу 28% та оцінки 76/16/8%. Фото обробляється локально, без надсилання серверу. Результати не зберігаються після перезавантаження. Іконка історії не має дії за рішенням користувача.

Каталог містить десять адаптивних карток із пошуком. Стаття — фото з лупою для курсора, опис, акордеон спостережень, дій та джерел. Фото й ліцензії: public/reference/ATTRIBUTION.md. Geist завантажується локально.

## Перевірки

```sh
npm run lint
npm run build
npm run test:coverage
npx playwright install chromium firefox webkit
npm run test:e2e
```

E2E запускає production preview на 5181. Вісім сценаріїв повторюються у Chromium, Firefox, WebKit і Mobile Chrome. Актуальні результати та межі — docs/verification.md. Конфігурація CI є, віддалений прогін не підтверджений.

## Структура та документація

- src/pages — активні LoginPage, AnalyzePage, DiseasesPage, DiseasePage.
- src/components — макет, навігація, дашборд, фото з лупою.
- src/services — підготовка фото та демонстраційний сервіс аналізу.
- src/domain і src/data — контракт результату, статті, атрибуція.
- docs/diagrams — редаговані draw.io-файли; output/report-assets — їхні знімки й скриншоти сайту.
- output/docx/coursework-report.docx — актуальна пояснювальна записка.
- docs/requirements-audit.md — перевірка вимог; META-USAGE — застосування ШІ.

Невикористані HistoryPage та wheatStorage видалено; /history перенаправляє на /analyze. Дані попередніх версій у браузері не видаляються.

Для курсової можна замінити analyzePhoto реальним API. Для розгортання зібрати dist та налаштувати SPA fallback. Backend, ML, експорт, офлайн/PWA в цій версії не реалізовано.

Мініатюри каталогу зберігаються в public/reference/thumbs у WebP 320/640/960. Оригінали залишені для детальних фото та лупи. Перше зображення завантажується пріоритетно, інші відкладено. Політика CSP не дозволяє eval; Zod працює в jitless-режимі. Мінімальні пороги модульного покриття: 80% кожного показника.

На ширині до 600 px бічну панель замінює верхня панель із бургером. Компактне меню містить аналіз, довідник, бездіяльну історію та акаунт. Воно закривається після переходу, Escape, натискання поза ним і зміни breakpoint. Авторизація залишається без навігації.
