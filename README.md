# Вебсистема моніторингу та діагностики хвороб зернових культур

Цей проєкт реалізовано в рамках STEM-завдання з дисципліни «Розробник фронтенду програмних систем». Це однокомпонентний SPA-додаток (тільки фронтенд) без серверної частини. API імітується через `localStorage`.

## Технології
- **UI:** React + TypeScript (Vite)
- **Роутинг:** React Router
- **Стилізація:** Tailwind CSS
- **Форми:** React Hook Form + Zod
- **Тестування:** Vitest, Playwright

## Як запустити

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```
3. Запустіть модульні тести (Vitest):
   ```bash
   npm test
   ```
4. Запустіть E2E тести та зробіть скріншоти (Playwright):
   ```bash
   npx playwright test
   ```

## Підключення моделі TensorFlow.js
За замовчуванням система використовує заглушку для діагностики. Щоб підключити реальну модель:
1. Навчіть модель в [Teachable Machine](https://teachablemachine.withgoogle.com/) на датасеті хвороб зернових.
2. Експортуйте модель у форматі TensorFlow.js.
3. Помістіть файли `model.json`, `metadata.json` та `weights.bin` у папку `public/model/`.
4. Змініть константу `USE_TF_MODEL` на `true` у файлі `src/services/diagnosisService.ts`.
5. Розкоментуйте код імпорту `@tensorflow/tfjs` та логіку завантаження моделі в цьому ж файлі.

## Структура проєкту
- `/src/components` - спільні UI компоненти
- `/src/pages` - сторінки додатка
- `/src/services` - сервіси (робота з API, авторизація, діагностика)
- `/src/schemas` - схеми валідації Zod
- `/src/context` - глобальний стан (AuthContext)
- `/tests` - E2E тести Playwright
- `/docs` - діаграми, скріншоти та інші матеріали для записки

## Реалізовані вимоги
| Вимога | Де реалізовано |
|--------|---------------|
| Адаптивність | `Tailwind CSS` класи у всіх компонентах. Перевірка на 360px-1920px. |
| Кросбраузерність | Проєкт тестується в Chromium, Firefox та WebKit через `Playwright`. |
| Захищеність | Валідація форм (`src/schemas/`), перевірка типу та розміру файлу (`PhotoUploader.tsx`), `CSP` в `index.html`. |
| UX | Індикатори завантаження (`Loader`), стани порожніх списків (`EmptyState`), зрозумілі помилки. |
